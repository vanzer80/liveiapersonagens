# Testes

Esta pasta deve concentrar testes automatizados e roteiros de validação técnica conforme o projeto evoluir.

Na fase atual, os testes prioritários são experimentais:
- conexão com LIVE;
- recebimento de comentários;
- identificação de usuários;
- estabilidade da sessão;
- comportamento em desconexão/reconexão;
- latência observada.

Evitar criar uma suíte complexa antes de existir código suficiente para justificá-la.
