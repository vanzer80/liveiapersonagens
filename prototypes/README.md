# Protótipos

Área destinada a experimentos pequenos e descartáveis usados para validar hipóteses técnicas antes de consolidá-las na aplicação principal.

Primeiro protótipo planejado: conexão com uma TikTok LIVE de teste e impressão dos eventos no terminal.

Cada protótipo deve registrar:
- objetivo;
- hipótese testada;
- como executar;
- resultado observado;
- limitações;
- decisão resultante, se houver.
