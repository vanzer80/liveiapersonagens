# Documentação técnica no GitHub

Esta pasta complementa — mas não substitui — a documentação oficial mantida no Google Drive.

Use `docs/` para registrar informações diretamente ligadas à implementação, como:

- desenho técnico do protótipo;
- contratos entre módulos;
- instruções de execução;
- decisões técnicas já aprovadas no projeto;
- resultados de testes que precisam acompanhar o código.

Decisões de produto, hipóteses, pendências e mudanças de escopo devem continuar sendo consolidadas na documentação oficial do projeto no Drive.
